# Auto Photo Uploader (Android)
Uploads every gallery photo to ImgBB automatically (and new ones later), in the background.

## Get the APK (no coding, free)
1. Make a free account on github.com → New repository → name it anything → Create.
2. "uploading an existing file" → drag ALL files/folders from this project (including the hidden `.github` folder) → Commit.
   (Easier on PC: unzip, then drag the contents in. On phone use "Desktop site".)
3. Open the **Actions** tab → "Build APK" runs by itself (≈3–5 min). If it doesn't, click it → "Run workflow".
4. Open the finished run → **Artifacts → AutoPhotoUploader-apk** → download, unzip, install the .apk
   (allow "Install unknown apps" when Android asks).

## Use
Open the app → "Allow & start" → choose **Allow all** photos → "Allow background (battery setting)" → set to Unrestricted.
Done. It keeps uploading by itself.
